# KeyboardGlass 0.1.7 experimental dynamic glass

Uses Theseus upstream 71ca1c127a4e7fe3387361f160c4890dbd427f66 (Apache-2.0), its original Metal shader, Gaussian blur and chrome composite. The keyboard adapter selects TabBar iOS27 chrome curve, blur.radius 18, edgeWidth 0, dispersion 0, interiorAverage 80, sharpness 0.48 light / 0.42 dark, neutralBodyScale 1 and edgeFeather 1/3. TabBar shade/glow algorithm is adapted to a 14-point rounded keyboard rectangle. No slider lens is instantiated.

System backdrop remains alpha 0.8, same original PNG fallback and seam coordinate logic as 0.1.4. Only full-width keyboard background regions get the dynamic view. Objective-C hooks install once. Source backdrop capture is experimentally changed to drawHierarchy(afterScreenUpdates:false) with only the alpha-0.8 native backdrop ancestor paths retained; all keys, tools and plugin glass are temporarily hidden and restored. Captures are not stored on disk. Main-thread capture and rendering capped at 15 FPS; offscreen/inactive keyboard pauses. A timeout restores original PNG. Nonempty capture does NOT prove actual App pixels; old compositor-frame feedback remains possible and requires device testing. This is a real shader integration but NOT validated dynamic appearance.

Build on macOS/Xcode or use manual GitHub Actions. build.py compiles real arm64e ObjC+Swift and original Metal, bundles resources beside the dylib, signs and verifies the extracted final package. No installation/respring is automatic. The original 0.1.0 seam release remains user-designated rollback stable; 0.1.4 remains available.
