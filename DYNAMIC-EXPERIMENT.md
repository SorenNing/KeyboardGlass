# KeyboardGlass 0.1.6 dynamic capture experiment

This 0.1.6 probe preserves the entire 0.1.4 appearance and original material, seam handling and system backdrop alpha 0.8. It samples at most three visible settled keyboard frames per process. In a disabled-actions transaction it retains only the ancestor path to the target system backdrop, temporarily hides other view subtrees, captures via layer.render and drawHierarchy(afterScreenUpdates:false), and restores hidden state in finally. The region is translated in point coordinates into a region-sized context at diagnostic scale 0.5. It logs only aggregate alpha, luminance, variance and a fingerprint of a 32x32 reduction. No captured image is displayed or written to disk. No keys or input text are read. drawHierarchy may still contain old compositor frames: nonzero pixels alone do not validate capture; correlate with App content changes and inspect feedback. This is an input probe, not a Theseus renderer or blur18 implementation. 0.1.0 remains the rollback baseline; 0.1.4 remains available.
